# TraceCrate v0.2.0 — focus, compare, share deliberately

The second TraceCrate release improves the local file-to-evidence workflow without adding accounts, telemetry, API keys or uploads. Native JSON remains **schemaVersion 1**; existing sharing defaults remain compatible.

**Live demo:** https://fankchen.github.io/tracecrate/ · [Research and design](https://github.com/FankChen/tracecrate/blob/v0.2.0/docs/v0.2-design.md)

## New

- **Focus the timeline:** combine literal search with event kind, status and minimum duration; sort longest-first without turning missing durations into zero. Search also covers IDs/model names. Reset and inspector close return keyboard focus.
- **Compare event sequences:** bounded kind/name alignment, changed field labels, tools-only scope, differences-only filter, pagination and links to the original event on either side. A match is not an execution identity or causal claim.
- **Minimize shared metadata:** structure-only export can omit all timing and/or token fields. The JSON preview, full JSON and script-free HTML use the same policy. Removed values remain unknown, including tool-duration summaries; pattern mode cannot use these controls because free text may repeat metadata.
- **Cancel an import, keep existing sessions:** ordinal batch progress, a 30-second per-file deadline, worker cleanup and stale-response rejection. Cancelling discards the pending batch, not the workspace.
- **OTLP compatibility:** nested key-value/array attributes, strict safe integers, current cache-write attribute with legacy fallback and explicit-zero precedence. Reported usage is still summed per span, not deduplicated by billing scope.

## Boundaries

Whole-file imports remain limited to 20 MiB/file, 20,000 records/events, five files per selection and ten sessions in memory. There is no persistence or streaming parser. Browser timers can be throttled; the deadline is not a hard real-time or memory guarantee.

Sequence comparison allows at most 2,000 selected events per side, 400 edits and a 200 ms alignment budget; exceeded limits produce **no partial diff**. Repeated names can align ambiguously. Analysis, comparison and export still run on the UI thread.

Structure-only still retains counts, order, status and remapped relationships, which can be sensitive. Neither export mode guarantees anonymization. Review the entire download. No benchmark improvement, full OTLP support, Firefox/WebKit coverage, screen-reader certification or independent security audit is claimed. All fixtures/screenshots are synthetic.
