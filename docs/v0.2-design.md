## Contract / 设计约束

### Focus

- Search is case-insensitive literal text, not user-provided regex. Search names, content, inputs, outputs, IDs and model names.
- Filters combine with AND. A minimum duration of zero includes recorded zero but excludes missing duration. Empty minimum disables that filter.
- Recorded order is default; longest-first is stable for equal durations, with unknown values last. Filtering/sorting never mutates source events.
- Keep 100 rows/page and the 50,000-character total detail cap. Clearing filters returns focus to search. Closing details returns to the originating row when available, otherwise search.

### Compare

- Align the recorded sequence by exact `(kind, name)` with jsdiff. IDs, absolute timestamps and parent links are **not cross-run identities**.
- Within aligned events compare exact content/input/output/status/model/duration and usage fields. Missing differs from zero or empty. Label changed fields; do not call a match the same execution or a causal explanation.
- Repeated names create ambiguous alignments; show that caveat. Insertions/removals mean only present on that side of this alignment, not success/failure.
- At most 2,000 selected events per side, 400 edits and a 200 ms alignment budget. Exceeding a bound yields an explicit unavailable state, never a misleading partial comparison. Optional tools-only scope can reduce the selected sequence. Timing budget is a guardrail, not a hard browser responsiveness guarantee.
- Show 50 comparison rows/page and allow inspection in the original timeline. No raw-diff export or new upload path.

### Minimize sharing metadata

| Field | Default structure-only | Omit timing | Omit token usage |
| --- | --- | --- | --- |
| Original text, names, models, unknown properties | Removed by existing allowlist | Removed | Removed |
| IDs / valid parent links | Remapped | Remapped | Remapped |
| Event order, kind, status, counts; demo flag | Retained | Retained | Retained |
| `timestamp`, `durationMs` on every event | Retained when present | **Absent** | Unchanged |
| Event and trace `usage` | Retained when present | Unchanged | **Absent** |
| Warnings | Fixed policy text | Fixed policy text | Fixed policy text |

- Both options are opt-in and reset when the dialog closes. Default output remains compatible with v0.1.0.
- Minimized metadata requires structure-only: free text in pattern mode can contain the same numbers. Switching to patterns clears the options; direct core calls requesting both patterns and minimization fail closed.
- Missing/removed summary values render **Unknown**, including tool duration sums with no measured calls. No zero substitution. Preview and downloads use the same transform.
- Counts, statuses, ordering and relationships may still identify a run. No anonymization or secure-erasure guarantee.

### Import lifecycle

- Fresh inline worker per file, sequential processing, existing size/depth/session caps unchanged.
- Deadline covers file reading + parsing + worker response, 30 seconds per file (browser timer throttling can delay enforcement). Terminate and clean up handlers/timers on every success/failure/abort path.
- Cancel stops the pending batch, discards all uncommitted batch results and preserves previously loaded sessions. Clear also removes those sessions. Generation checks reject late responses. No partial trace is published.
- Show file ordinal progress, not fabricated byte/percentage progress. No filename/content logging. Whole-file parsing remains; no memory ceiling is promised.

### OTLP compatibility

- Decode nested `kvlistValue`/`arrayValue` into inert JSON; null-prototype maps protect arbitrary attribute keys. Integer values must really be safe integers, not empty/null/boolean coercions.
- Prefer `gen_ai.usage.cache_write.input_tokens`, even if explicitly zero; fall back to `gen_ai.usage.cache_creation.input_tokens`. Never add both. Warn generically if valid aliases conflict.
- Keep per-span reported usage summation; do not infer billing deduplication, cache-write counts absent from Codex, or unreported statuses.

## Release gates / 验收

1. All old tests pass; new pure tests cover filter unknowns/stability, alignment limits/repeated names, all four minimization combinations, worker races/deadlines and structured OTLP compatibility.
2. Browser tests cover actual preview/download/reimport bytes, zero network during local work, keyboard/focus, cancellation/timeout, comparison navigation, pagination and mobile overflow.
3. Lint, TypeScript/build, dependency audit and core coverage are recorded honestly. Chromium runs in GitHub Actions if local browser binaries remain unavailable; do not bypass enterprise download restrictions.
4. Publish matching English/Chinese docs, changelog, verification evidence, static-site archive with checksums, and the v0.2.0 GitHub release only after the candidate passes. Verify the actual Pages deployment separately.

Out of scope: cloud ingestion, accounts/telemetry, LLM scoring/cost estimates, persistence, streaming import, full span trees, distributed billing inference, runtime plugins, blanket major dependency upgrades and Firefox/WebKit/screen-reader certification.
